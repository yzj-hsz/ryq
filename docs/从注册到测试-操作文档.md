# 饶有趣 ryq · 从注册 GitHub 到测试全流程操作文档

> 仓库：`https://github.com/yzj-hsz/ryq.git`，分支 `main`
> 三端：后端 `backend/`（Flask :5000）+ 小程序 `miniapp-taro/`（Taro 4）+ 管理端 `admin-web/`（Vite :5173）
> 本机实测环境：Node v22.20.0、Python 3.13.9，满足 README 要求的 Node 18+、Python 3.10+

***

## 1. 注册 GitHub

1. 打开 `github.com` → Sign up，准备一个常用邮箱 + 手机号（收验证码）。
2. 用户名建议用英文，密码 15 位以上含大小写+符号。
3. 开启二次验证（2FA）：手机装 Authenticator，按向导扫码并备份恢复码。
4. 本机配置 Git（Windows 用 PowerShell）：

```powershell
git --version
git config --global user.name "你的英文名"
git config --global user.email "你的GitHub邮箱"
```

1. 本仓库是 HTTPS 地址，无需配 SSH 即可克隆；push 需要登录授权（浏览器弹窗或 Personal Access Token）。如果是协作者，让管理员在 GitHub → Settings → Collaborators 拉你进仓库。

## 2. 克隆仓库

```powershell
# 选一个英文无空格目录，如 C:\code
git clone https://github.com/yzj-hsz/ryq.git
Set-Location ryq
git branch --show-current   # 应为 main
git status --short          # 干净为正常；若看到 navigation 等 M 改动，属本次修复未提交内容
```

目录结构（见 `README.md`）：

```text
ryq/
├─ admin-web/              # React 管理端

│  ├─ migrations/          # Alembic 迁移
```

项目**不包含线上交易、支付和结算**，商品详情核心 CTA 是“我想要”二维码引流。

## 4. 启动后端 `backend/`

```powershell
Set-Location backend
py -3 -m pip install -r requirements.txt
# 要跑测试再装：
py -3 -m pip install -r requirements-dev.txt

# 首次配置环境变量
Copy-Item .env.example .env
```

`.env` 开发最小配置（`backend/.env.example` 原样即可跑）：

```env
APP_ENV=development
ALLOW_PLACEHOLDER_SEED_DATA=true
DATABASE_URL=
JWT_SECRET=
WX_APPID=
WX_SECRET=
WECHAT_ALLOW_MOCK=true
ADMIN_USERNAME=admin
ADMIN_PASSWORD=admin123
ADMIN_EMAIL=admin@example.com
EMAIL_PROVIDER=mock
```

说明：

- `DATABASE_URL` 留空默认用 `backend/data.db`
- `APP_ENV=development` 允许部分开发 mock
- 生产必须配 `JWT_SECRET`、`WX_APPID`、`WX_SECRET`，否则拒绝启动
- `WECHAT_ALLOW_MOCK=true` 仅开发允许微信占位 openid

初始化 + 启动：

```powershell
py -3 -m flask --app run.py db current   # 看当前版本，应为 c3d4e5f6a7b8
py -3 -m flask --app run.py db upgrade   # 升到最新
py -3 run.py                             # 启动，http://127.0.0.1:5000，入口 backend/run.py
```

真实素材同步（把 `img/` 写入数据库 + `raoyouqu/static/uploads/`）：

```powershell
py -3 scripts/sync_img_assets.py
```

## 5. 启动小程序 `miniapp-taro/`

```powershell
Set-Location ../miniapp-taro
npm install
npm run dev:weapp
```

- 编译产物在 `dist/`，`src/` 为源码，API 基址由 `TARO_APP_API_BASE` 决定，默认 `http://127.0.0.1:5000/api/v1`（见 `config/index.ts`）。
- 微信开发者工具 → 导入项目 → 目录选 `miniapp-taro/` → AppID 先用测试号/开发版 → 勾选“不校验合法域名”即可调本地 5000。
- 自定义后端地址：

```powershell
$env:TARO_APP_API_BASE="http://192.168.x.x:5000/api/v1"; npm run dev:weapp
```

## 6. 启动管理端 `admin-web/`

```powershell
Set-Location ../admin-web
npm install
npm run dev   # http://127.0.0.1:5173
```

改 API 地址二选一：启动前设 `$env:VITE_API_BASE="http://127.0.0.1:5000/api/v1"`，或浏览器注入 `window.__RYQ_ADMIN_API_BASE__`。默认已指向本地 5000。

默认管理员（无管理员时按 `.env` 自动写入）：`admin / admin123 / admin@example.com`，生产务必改。

## 7. 联调验证（3 分钟冒烟）

1. 后端 5000 有响应：浏览器开 `http://127.0.0.1:5000/api/v1` 不 404。
2. 管理端 5173 登录 admin 成功，进商品/礼盒页能看到数据。
3. 小程序开发者工具 Console 无红字，进首页视频、礼盒选配、商品详情点“返回”不再报 `navigateBack:fail cannot navigate back at first page`（本次 `utils/navigation.ts` 修复点）。
4. 礼盒流程：未登录点保存弹`未登录无法使用此功能`→去登录→登录后回跳 `custom?box_id=原id`。

### 8.3 手工回归（对应当前未提交改动）

- 返回键：18 个改动页各测“正常栈返回”+“reLaunch 直进点返回走 fallback”，Console 无报错。
- 登录回跳：`login/login.tsx`、`email-login.tsx` 的 `redirect` 透传，微信/访客/邮箱三路登录后均回原页。
- 访客拦截：`giftbox/custom.tsx interceptGuest`，none/guest/401 三态弹窗文案与 `auth-tip-row` 提示条一致。
- API 文档有改接口时：`py -3 scripts/generate_apifox.py` 重生成 `apifox.json` 再提交，不手改 JSON。

鉴权速查（见 `README.md`）：

- 微信登录 `POST /api/v1/auth/wechat`，邮箱 `POST /api/v1/auth/send-code` + `POST /api/v1/auth/email-login`，访客 `POST /api/v1/auth/guest`
- 管理员 `POST /api/v1/admin/auth/login`，头 `Authorization: Bearer <token>`，用户 `typ=user`、管理 `typ=admin` 不可混用

上传规则：用户端只允许图片（10MB），管理端允许图片 20MB + 视频 100MB，均校验后缀/MIME/真实内容。

## 9. 常见问题

| 现象                         | 处理                                                                         |
| -------------------------- | -------------------------------------------------------------------------- |
| 5000 被占                    | `netstat -ano \| findstr 5000` 杀进程，或换端口改三端 API 基址                          |
| `pip install Pillow` 失败    | `py -3 -m pip install -U pip` 后用官方源重装                                      |
| 小程序报 `navigateBack` 红字     | 确认走 `navigateBackOrRelaunch` 且 fallback 是已注册页面                             |
| 微信登录 401/mock 失效           | 检查 `.env` 的 `WECHAT_ALLOW_MOCK`，生产不允许 mock                                 |
| `git status` 出现 LF/CRLF 警告 | Windows 正常提示，不影响编译，勿批量转行尾                                                  |
| MySQL 切换                   | `.env` 配 `DATABASE_URL=mysql+pymysql://user:pwd@host/ryq` 后重跑 `db upgrade` |
