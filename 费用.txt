饶有趣 ryq · 小程序一年运维费用汇总（费用.txt）
==================================================
项目构成：miniapp-taro（微信小程序 Taro4）+ admin-web（React管理端）+ backend（Flask）
无线上交易/支付/结算，无支付手续费。以下为每年必续/按量支出，按 2026 年腾讯系官方定价估算。

【说明】
1. 微信认证费按次/按年审：企业 300元，个体户 30元。
2. 服务器首年便宜、续费贵，下面分开标了“首年价 / 续费原价”。
3. 本项目当前是邮箱验证码+微信+访客登录，无短信；短信列为“可选，想加才花”。
4. 数据库默认 SQLite 自建 0 元，切云 MySQL 才收费。

--------------------------------------------------
一、一年详细费用支出（标准生产档，按续费价算）

1. 微信小程序认证费 --- 300元
   企业/有限公司主体，微信官方审核服务费，一年一审。个体户 30元，政府/基金会免费。

2. 域名注册费（.cn 首选备案用） --- 35元
   .cn 首年约 28-35元，续费约 35-40元/年；.com 约 68-80元/年。本单按 1 个 .cn 计。

3. 域名注册费（.com 备用，可选） --- 0元
   只用一个域名可不买。若双域名，另加约 75元/年。

4. SSL 证书 --- 0元
   腾讯云/阿里云免费版 DV（3个月一续，自动续签）或 Let's Encrypt，对展示型小程序够用。付费 OV 约 1000元起，不需要不买。

5. 云服务器（腾讯云轻量 2核4G6M/70G/600G流量，跑 Flask+管理端够用） --- 900元
   首年活动价约 199元/年（可同价续 1 次），之后恢复原价约 900元/年。
   长期最低可 528元/3年（2核4G活动款，折约 176元/年），小流量展示站够用。
   注：本行按续费原价 900元计，首年按 199元计。

6. 对象存储 COS（图片/视频：用户10MB、管理20MB+视频100MB） --- 120元
   标准存储 + CDN 回源流量小体量估算：50G 存储约 60元/年 + 流量/请求约 60元/年。
   量小可压到 50元内，视频多则上浮到 300元+。

7. CDN / 流量费（小程序封面、礼盒图、手作图加速） --- 0元
   小流量时含在轻量流量包（600G/年）+ COS 免费额度内，不单独买。量大另加约 200-500元/年。

8. 云数据库 MySQL（可选，自建则 0 元） --- 0元
   当前默认 SQLite 在服务器本地跑，0 元。切腾讯云 MySQL 基础版约 1000-2000元/年，展示量没必要。

9. 短信费（可选，当前用邮箱验证码，不用不花） --- 0元
   若加手机验证码：腾讯云短信 1万条包 470元/2年（0.047元/条），折约 235元/年。
   1000 条自定义包约 50元（0.05元/条）。本单按未启用计 0 元。

10. 邮件推送费（邮箱验证码登录用） --- 0元
    量小用阿里云邮件推送免费额度 / 企业邮免费版 / 自建 SMTP，0 元。
    量大：阿里云邮件推送约 300-600元/年。本单按小量计 0 元。

11. 管理端托管 --- 0元
    与后端共用同一台轻量服务器（Nginx 反代 :5173 构建产物），不单独买主机。

12. 备案、运维杂费（ICP备案0元、备份硬盘、监控、日志） --- 50元
    ICP/公安备案 0 元；预留云硬盘快照/备份/告警短信小额，约 50元/年。
    人工维护、版本迭代人力不计入。

--------------------------------------------------
二、综合合计

A. 极简自建档（首年活动价 + SQLite + 免费证书/邮件 + 不用短信/云库）
   微信认证费300 + 域名35 + 服务器首年199 + COS约50 + 杂费约20 = 约 604元/年
   若个体户认证（30元）：约 334元/年即可跑起来

B. 标准生产档（续费原价口径，本文件明细 sumar）
   300 + 35 + 0 + 0 + 900 + 120 + 0 + 0 + 0 + 0 + 0 + 50 = 约 1405元/年
   四舍五入：约 1400-1500元/年

C. 加短信+云数据库的高配档
   标准 1405 + 短信235 + 云MySQL约1200 = 约 2840元/年
   即：约 2800-3500元/年

--------------------------------------------------
三、一句话结论
首年最省：约 600元（企业认证）/ 约 330元（个体户）拿下；
往后每年常态：约 1400元左右；
要加短信+云数据库：每年约 2800元起。
本项目无支付分账，无额外佣金。

数据依据（2026）：微信认证企业300元/个体户30元；腾讯云轻量2核4G首年199元可同价续1次、原价约900元/年；
腾讯云短信1万条470元/2年（0.047元/条）、1000条约0.05元/条；.cn约35元/年、.com约75元/年。
